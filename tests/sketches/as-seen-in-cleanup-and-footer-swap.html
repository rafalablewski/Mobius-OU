The "AS SEEN IN" duplicate — cleanup + footer swap

The press credit appears twice in the shipped UI: once at the top of Home.jsx / About.jsx via <PressLine variant="marquee" />, and again in the footer via <PressLine variant="static" /> at Footer.jsx:66. The homepage one also stacks four hairlines in two different colour tokens against the .ht-stats-area tile below it. This file pairs the two fixes side by side — Part A redesigns the homepage strip to fix the doubled lines, Part B replaces the footer instance with the Google + Trustpilot SVG badges already shipped at /public/google.svg and /public/trustpilot.svg.

The two hairlines today

rgba(11,15,20,0.20) — cooler, ink-tinted. Used on .ht-press-line top + bottom (style.css:16084).

var(--ht-border-color) = #E2DBCE — warmer, paper-tinted. Used on .ht-stats-area top + bottom (style.css:13378).

Same weight (1 px), different colour temperature. On cream they read as two systems, not one.

The footer duplicate

Footer.jsx:66 renders the same press credit as Home.jsx and About.jsx — four wordmarks every page. No new information. The replacement asset (RatingProof.jsx) already exists and ships on the Contact page; this file shows five ways to drop it into the footer band instead.

Recommendations — ship A.I + B.II

Part A · variant I (no press-line border) is the cleanest fix for the doubled-rules problem and keeps every other component untouched. Four rules drop to two, in one consistent token. A.III (unify the colour) is the one-line CSS fallback if we'd rather not lose the press-line frame.

Part B · variant II (eyebrow + left-aligned row) matches the footer's existing typographic system (the same eyebrow style the four widget columns use), keeps the badges at a readable 84 px, and avoids stacking another row of hairlines next to the copyright divider. B.III (rail) is the fallback for the lightest treatment.

Both Home.jsx and About.jsx render PressLine.jsx's marquee variant, so the Part A CSS change automatically applies to both pages.
