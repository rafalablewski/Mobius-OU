Recommendation — ship II (eyebrow + left row)

II matches the footer's existing typographic system (the same eyebrow style the four widget columns use), keeps the badges at a readable 84 px, and avoids stacking a second row of hairlines next to the copyright divider. III (rail) is the fallback if we want the very lightest treatment. I is the largest signal but reads heavy in the footer band.

All five reuse the existing /public/google.svg and /public/trustpilot.svg assets — no new files. The implementation change in Footer.jsx is a one-line swap; RatingProof.jsx gains a tone or size prop to pick the footer variant.
